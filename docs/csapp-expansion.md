## 范围

保留三个部分、27 个主题、54 个场景及 216 个演示阶段。未更改 IsoKit 图形、事件、状态、箭头、播放机制、布局或页签。每个现有主题新增三个机制说明段落、CSAPP 关联说明和具体章节入口，共 81 个解释段落。搜索包含新增正文。播放期间保留机制与来源面板的阅读位置；切换主题或页签时从顶部阅读。

这些文字是为站点编写的独立教学解释，不是电子书章节转录。示例数字、场景状态与原演示保持一致，另给出的地址或性能数字明确作为算例。

## 依据边界

- 所给电子书的第 4、5、6 章在核查时仅有标题。因此未把它们列为有正文支撑的阅读入口。缓存的深入机制仍保留 CMU 资料，乱序执行与退休仍保留 Intel 资料。
- §12.5 的进度图适合说明单核交错与临界区，不能直接证明现代多核内存序。原子操作与内存序沿用已有专业参考。
- CSAPP 不构成 MVCC、OCC、WAL、ARIES、Raft、分布式线性一致性、分片迁移或 Outbox 的算法来源。详情中的“CSAPP 关联与阅读”明确说明基础联系，来源页保留各主题的数据库、论文或官方工程资料。
- WAL 同步 I/O 的补充核对了 PostgreSQL 18 WAL 文档和 Linux fsync(2) 手册，未将 write 返回成功等同于持久化完成。
- 原有来源与教学场景不因新增关联而变成 CSAPP 的原文示例；术语类似不表示机制等价，例如页级 COW 与事务 MVCC、互斥锁与事务提交、TCP 顺序与业务全序。
